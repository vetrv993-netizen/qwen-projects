نظام المحاسبة وإدارة الأعمال

تطبيق سطح مكتب أصلي مبني بـ Python و PySide6

🖥️ Native Desktop Application — NOT a Web App

⚠️ ملاحظة مهمة

هذا المشروع هو تطبيق سطح مكتب أصلي مبني بـ Python/PySide6/SQLite.
هذه الصفحة هي فقط لتوثيق المشروع. التطبيق الفعلي يعمل كـ EXE مستقل على Windows.

للتشغيل: python main.py أو build.bat لبناء EXE

🔧 التقنيات المستخدمة

Python 3.10+ لغة البرمجة الأساسية
PySide6 واجهة سطح المكتب
SQLite قاعدة البيانات المحلية
bcrypt تشفير كلمات المرور
PyInstaller بناء ملف EXE
pytest اختبارات تلقائية

🚀 كيفية التشغيل

# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل التطبيق مباشرة
python main.py

# أو بناء ملف EXE مستقل
build.bat
# الناتج: dist\AccountingSystem.exe

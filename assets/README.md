# Assets Directory

This directory contains application resources:

- `icon.ico` - Application icon (generated by `generate_icon.py`)
- `icon_256.png` - 256x256 PNG version
- `icon_512.png` - 512x512 PNG version

## Generating the Icon

Run the icon generator script:

```bash
python generate_icon.py
```

This will create:
- `assets/icon.ico` - Multi-size ICO file for Windows
- `assets/icon_256.png` - 256x256 PNG
- `assets/icon_512.png` - 512x512 PNG

The icon is automatically generated with a professional blue design featuring a ledger/book symbol with a checkmark.

## Icon Usage

The icon is used in:
- PyInstaller EXE (embedded in the executable)
- Login window
- Main application window
- Windows taskbar

If the icon file doesn't exist, the application will use the system default icon.

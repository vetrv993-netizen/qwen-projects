Windows build instructions
==========================

Use Python 3.11.x. The project pins PySide6 6.7.3, which is not compatible with Python 3.14.

From this project directory:

1. Create/activate venv311:
   py -3.11 -m venv venv311
   .\venv311\Scripts\Activate.ps1

2. Install dependencies:
   python -m pip install -r requirements.txt

3. Run tests:
   python -m pytest -q

4. Run the application:
   python main.py

5. Build EXE:
   python -m PyInstaller --clean --noconfirm app.spec

6. Verify:
   Test-Path .\dist\AccountingSystem.exe

Expected result:
   .\dist\AccountingSystem.exe

Do not use Python 3.14 with the pinned PySide6 6.7.3 requirement.
